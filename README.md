# 🍴 Recipe Box

Welcome to **Recipe Box**, a simple and user-friendly recipe website where you can explore delicious meals, desserts, and cooking ideas.

## Preview
https://cinderella-mpu.github.io/RecipeBox/homepage.html

## 📖 About the Project

Recipe Box was created as a web development project to provide an easy way for users to discover recipes and cooking tips.

The website includes different food categories, recipe information, preparation times, and helpful cooking tips.

## ✨ Features

* 🏠 Home page with food images
* 🍲 Recipe categories
* 📋 Recipe pages with preparation times
* 🍰 Dessert recipes
* 💡 Cooking tips
* 🖼️ Food images
* 📱 Simple and user-friendly layout
* 🎨 Custom CSS styling

## 🍽️ Recipe Categories

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/cinderElla-mpu/RecipeBox.git
```

2. Open the project folder.

3. Open `homepage.html` in your web browser.
